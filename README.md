# Customer Segmentation System

## 🚀 Overview
A machine learning web app that segments customers using K-Means clustering.

## 🧠 Features
- Upload your dataset
- Choose number of clusters
- Visualize customer groups
- Get business insights

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn

## ☁️ Deployment
Deployed on Streamlit Cloud

## 📊 Use Case
Helps businesses understand customer behavior and improve marketing strategies.
